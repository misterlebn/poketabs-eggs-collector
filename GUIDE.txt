POKETABS EGGS COLLECTOR - GUIDE RAPIDE (V00.11.00)

1. AVANT DE LANCER LE JEU (une seule fois)
   Double-clique sur INSTALLER_SPRITES.bat.
   Il copie depuis Everything is Métamorph les fichiers utiles au jeu
   (Pokémon normaux et shiny, œufs, objets, arbres) dans le dossier "sprites".
   Les meubles de la nurserie (nids, griffoirs, plantes) sont déjà dans "assets".

2. TESTER SUR TON ORDI
   VS Code + extension "Live Server", clic droit sur index.html > "Open with Live Server".
   La partie est sauvegardée dans le navigateur (localStorage).
   Pour recommencer à zéro : console du navigateur (F12) > localStorage.clear() puis F5.

3. OÙ MODIFIER QUOI (dans index.html, Ctrl+F)
   const T=          durées de ponte et d'éclosion, mutation, chances shiny, XP, puissance des combats
   const INC_CAP=    nombre d'œufs par incubateur selon son niveau
   const BALL_SLOT=  nombre de Pokémon par punching-ball selon son niveau
   const SHOP=       objets de la boutique, prix et effets
   function eggPrice     prix de chaque œuf du marché (légendaires très chers)
   const BIOMES=     les 24 biomes du continent (couleurs, arbres, types d'ennemis), 10 tableaux par biome (PER_BIOME). Le 25e est la Route Victoire (VICTORY_POOL : les 45 plus forts non légendaires), ses 5 derniers tableaux sont la Vallée des légendes (VALLEY, LEGEND_POOL). 250 tableaux en tout
   enemyLv()         courbe de niveau des ennemis (exposant .6 : plus dur au début)
   GENS, DEAL_*      boutique « Œufs du moment » : 1 œuf par génération, -30 %, renouvelée chaque heure, 15 % de chance d'un œuf légendaire
   superEgg()        super œuf rare niveau 10 donné par chaque boss de fin de biome ; les autres boss donnent un œuf niveau 5
   function enemyLv  niveau des ennemis par tableau (et en mode Maître : niveau du meilleur Pokémon)
   function genEnemies   taille et niveau des armées ennemies, bosses (tous les 5 tableaux)
   function evoLevel     niveaux d'évolution
   const FB_CONFIG=  configuration Firebase (vide pour l'instant)

4. CONNEXION GOOGLE (plus tard)
   - Firebase : créer le projet "poketabs-eggs-collector", activer Authentication > Google
     et Firestore, ajouter une application Web, copier sa config dans FB_CONFIG.
   - Ajouter le domaine GitHub Pages dans Authentication > Settings > Authorized domains.
   - Règle Firestore conseillée (même principe que Métamorph) :
     match /saves/{uid} { allow read, write: if request.auth != null && request.auth.uid == uid; }

5. METTRE EN LIGNE
   GitHub : nouveau dépôt, envoie index.html, assets et sprites, puis Settings > Pages.
   Jeu privé entre amis : les sprites Pokémon ne doivent pas servir à une version publique.

CLASSEMENT EN LIGNE (V00.11.00)
   Chaque joueur connecté publie un profil public dans la collection Firestore « profiles » (pseudo, titre, tableau, Pokédex, succès, ses 60 meilleurs Pokémon).
   Règle à ajouter dans Firebase > Firestore Database > Règles, à côté de la règle « saves » :
     match /profiles/{uid} {
       allow read: if true;
       allow write: if request.auth != null && request.auth.uid == uid;
     }
   TITLES   titres débloqués par les succès (onglet Succès : pseudo et titre affiché)
   LEGEND_ORDER   boss légendaires du plus faible (tableau 10) au plus fort (tableau 240) ; FINAL_BOSS = Arceus au tableau 250
